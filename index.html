How it works

chatlens is a single HTML file that runs entirely in your browser. When you drop an export, a background Web Worker parses it and builds a full-text index in memory. There is no backend and no network activity — you can verify this in your browser's Network tab, or disconnect from the internet and it still works.

Export from ChatGPT

  1. ChatGPT → Settings → Data controls → Export data.
  2. You'll get an email with a .zip. Unzip it.
  3. Drop the conversations.json file here.

Export from Claude

  1. Claude → Settings → Privacy → Export data.
  2. Unzip the archive you receive by email.
  3. Drop its conversations.json here.

Search tips

Multiple words match messages containing all of them. Wrap a phrase in "quotes" for exact matches. Prefix with / and end with / for a regular expression, e.g. /colou?r/. Use the role filters to show only your messages or only the AI's.

Is anything saved?

No. Everything lives in memory for the current tab only. Reload the page and you start fresh. Nothing is written to disk, cookies, or any server.
